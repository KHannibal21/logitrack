# LogiTrack: i18n + Welcome Screen + Language Switcher

## ✅ Что было реализовано

### 1. **Полная поддержка многоязычности (i18n)**
   - **Языки:** Русский (ru) и Казахский (kk)
   - **Файл:** `utils/i18n.ts`
   - **Восстановлены все переводы:**
     - Авторизация (вход, регистрация, восстановление пароля)
     - Заказы и статусы
     - Склад/Инвентарь
     - Управление пользователями
     - Профили и роли
     - Валидация и ошибки
     - **Новое:** Профиль, Language Selection, Welcome Screen

### 2. **Language Switcher (Переключатель языков)**
   - **Новый компонент:** `components/LanguageSwitcher.tsx`
   - **Функционал:**
     - Bottom sheet modal с выбором языков
     - Визуальное отображение текущего языка (выделение всегда активного языка)
     - Сохранение выбранного языка в AsyncStorage
     - Автоматическое применение при перезагрузке приложения
   
   - **Интеграция в профили:**
     - `app/(admin)/profile.tsx`
     - `app/(dispatcher)/profile.tsx`
     - `app/(courier)/profile.tsx`
   
   - **UI:** Кнопка "Язык" 🌐 рядом с кнопкой выхода

### 3. **Welcome Screen (Приветственный экран)**
   - **Новый компонент:** `components/WelcomeScreen.tsx`
   - **Дизайн:**
     - Градиентный фон (primary → tabIconDefault)
     - Центрированное содержимое
     - Название app (LOGITRACK) крупным шрифтом
     - Заголовок, подзаголовок и описание на выбранном языке
     - Белая кнопка "Начать" с shadow
   
   - **Поведение:**
     - Показывается при первом входе пользователя
     - Флаг сохраняется в AsyncStorage по UID пользователя
     - Не показывается повторно при повторных входах
     - Полностью локализирован (ru + kk)

### 4. **Hooks для управления языком**
   - **`useLanguage.ts`** - основной hook
     - `changeLanguage(lang)` - смена языка + сохранение в AsyncStorage
     - `currentLanguage` - текущий язык
   
   - **`useLanguageInitializer.ts`** - инициализатор языка
     - Загружает сохранённый язык при запуске
     - Применяется при первой загрузке приложения (в `_layout.tsx`)

### 5. **Интеграция в приложение**
   - **Главный layout:** `app/_layout.tsx`
     - Проверка, был ли пользователь показан Welcome Screen
     - Условное отображение WelcomeScreen или основного контента
     - Вызов useLanguageInitializer для восстановления сохранённого языка

## 📱 Пользовательский опыт

### При первом входе:
1. Пользователь видит приветственный экран (Welcome Screen)
2. На экране: название приложения, описание и кнопка "Начать"
3. После нажатия - переход в приложение
4. Флаг сохраняется - экран больше не показывается

### Выбор и сохранение языка:
1. Пользователь открывает свой профиль (Admin/Dispatcher/Courier)
2. Нажимает кнопку "Язык" 🌐
3. Выбирает между Русским 🇷🇺 и Казахским 🇰🇿
4. Язык применяется немедленно
5. Язык сохраняется и автоматически применяется при следующих входах

## 🔧 Технические детали

### Перевод ключей i18n:
```
app.name              - Название приложения
profile.language      - "Язык" / "Тіл"
profile.changeLanguage - "Выберите язык" / "Тілді таңдаңыз"
profile.russian       - "Русский" (всегда)
profile.kazakh        - "Қазақша" (всегда)
welcome.title         - Заголовок приветствия
welcome.subtitle      - Подзаголовок
welcome.description   - Описание
welcome.getStarted    - Кнопка "Начать"
cancel                - "Отмена" / "Болдырмау"
```

### Хранение данных:
- **selectedLanguage** (AsyncStorage) - выбранный язык пользователя
- **welcome_{uid}** (AsyncStorage) - флаг просмотра Welcome Screen

### AppConfig:
```typescript
SUPPORTED_LANGUAGES: ['ru', 'kk']
DEFAULT_LANGUAGE: 'ru'
```
